Detailed Description

Abstract base class representing a generic DT model m ∈ M of DT = ⟨D, M, S, μ⟩.

M is the set of DT models that represent the ToI virtually: M = M_desc ∪ M_pred ∪ M_presc, the descriptive (DT_Model_Descriptive), predictive (DT_Model_Predictive) and prescriptive (DT_Model_Prescriptive) models.

Every model belongs to the class of automata 𝒜 (M ⊆ 𝒜); hence this class extends DT_Automaton and inherits the 7-tuple ℳ = ⟨Λ, X, Y, Σ, Φ, Δ, Δ*⟩. A model is updated by the data assimilation function μ through assimilate.

◆ assimilate()

void Models.DT_Model< T >.assimilate ( DT_DataSegment< T > omega)

Assimilates a data segment into this model: the model side of μ(ω, m) = m'.

The model is updated in place, so m' keeps the type of m. By default each datum of ω is passed to update in time order; subclasses can override it (e.g., to re-train a predictive model on a whole historical segment).
