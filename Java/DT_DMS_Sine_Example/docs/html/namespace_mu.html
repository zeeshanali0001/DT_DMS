Detailed Description

This package contains the model inference or data assimilation function (μ) of the DT-DMS framework.

μ : Ω_D × M → M updates a model with a data segment: μ(ω, m) = m', where m' keeps the type of m. Real-time data is assimilated synchronously and historical data asynchronously; a mixed segment is split into ω_hist ⊕ ω_rt or assimilated as a whole. The description for each class in the Mu package is as follows:

  • DT_Mu: the data assimilation function. It observes the data sources and updates the models.
  • ObserverData: the observer of the data observer pattern (models, services and μ).
  • ObserverDataManager: the subject of the data observer pattern (the data sources).
