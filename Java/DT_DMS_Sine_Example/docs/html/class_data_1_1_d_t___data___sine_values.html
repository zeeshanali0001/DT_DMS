Detailed Description

Data source of the sine example: it plays the role of the ToI (the "physical twin") and produces the sine wave values measured over time.

Each call to measure produces the datum d = ω(t) = sin(t) measured at time t and records it; the observers (the data assimilation function μ) are notified at once. An anomaly can be injected to test the diagnosis service.
