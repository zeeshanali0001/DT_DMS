Detailed Description

Represents a prescriptive model (m ∈ M_presc) of the Digital Twin.

A prescriptive model tells what should be done on the ToI: from the data it has assimilated, it recommends the action to take in order to reach an objective.

<T>the type of a datum d ∈ D.
