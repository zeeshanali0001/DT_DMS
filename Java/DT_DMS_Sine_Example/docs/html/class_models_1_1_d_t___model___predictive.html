Detailed Description

Represents a predictive model (m ∈ M_pred) of the Digital Twin.

A predictive model tells what is likely to happen in the ToI: it uses the historical and real-time data it has assimilated to predict future states or behaviours.

<T>the type of a datum d ∈ D.
