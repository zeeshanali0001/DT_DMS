Detailed Description

Main class of the Sine Wave Cubic B-Spline Digital Twin example: a minimal "Hello World" Digital Twin DT = ⟨D, M, S, μ⟩ built with the DT-DMS framework.

  • D: the sine values measured on the ToI (DT_Data_SineValues).
  • M: one descriptive model, the Cubic B-Spline (DT_Model_Descr_CubicBSpline).
  • S: one diagnosis service (DT_Service_Diagnosis_Sine), coupled to the model.
  • μ: the data assimilation function of the framework; it observes the data and updates the model.

Information flow for each sample: Data → μ → Model → Diagnosis, with live charting and anomaly detection. The model and the service are both specified as automata (see their classes).

◆ execute()

void DT_DMS_SineCubicBP.execute ( int nbVal)

Runs the simulation: measures nbVal sine values, one per step.

For each value:

  1. the data source measures the ToI at t_now;
  2. μ assimilates the real-time datum synchronously into the model;
  3. the diagnosis service is run on the datum, s(m, ω);
  4. the chart is updated.
Parameters
nbValthe number of values to measure.
