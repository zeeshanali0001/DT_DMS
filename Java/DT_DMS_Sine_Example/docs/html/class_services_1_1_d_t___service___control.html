Detailed Description

Class representing a Control Service (s ∈ S_cont) of the Digital Twin.

A Control Service acts back on the ToI (through actuators or other systems) based on feedback: it turns the latest consumed value and the target of the coupled prescriptive model into a command.

<T>the type of a datum d ∈ D.
