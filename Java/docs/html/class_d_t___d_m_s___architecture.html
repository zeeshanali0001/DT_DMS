Detailed Description

The DT_DMS_Architecture class connects all classes of the DT-DMS framework.

It is a Digital Twin (DT_DMS) with one named component of each kind: one data source, the three types of models, the five types of services and the data assimilation function. Its collaboration diagram (generated by Doxygen/Graphviz) is the architecture image of the framework.

Assign the fields, then call connect() so that every component belongs to D, M or S and is reached by μ.

Note: the fields are declared without their type argument (e.g., DT_Data instead of DT_Data<T>) on purpose: Doxygen draws the relation to a class, with its parent classes, only for this form. In your own code, use the typed form, as done in main.
