Detailed Description

Class representing an Optimization Service (s ∈ S_opti) of the Digital Twin.

An Optimization Service finds the best solution for the ToI (performance, resource allocation, ...). It relies on the prescriptive model it is coupled to for the recommendation.

<T>the type of a datum d ∈ D.
