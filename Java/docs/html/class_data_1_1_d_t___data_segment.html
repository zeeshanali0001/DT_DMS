Detailed Description

Class representing a measured data segment ω ∈ Ω_D of the Digital Twin.

A data segment is a partial function ω : T_U ⇀ D from universal time T_U to data, with Dom(ω) ⊆ T_U and Im(ω) ⊆ D. Time is a double (e.g., seconds). Since a segment is measured, no datum lies in the future: sup Dom(ω) ≤ t_now.

With t_now the current time and δ the freshness threshold (data scope), a segment is:

  • real-time, ω ∈ Ω_D^rt(t_now), iff inf Dom(ω) ≥ t_now − δ ∧ sup Dom(ω) ≤ t_now;
  • historical, ω ∈ Ω_D^hist(t_now), iff sup Dom(ω) < t_now − δ;
  • mixed, ω ∈ Ω_D^mix(t_now), iff inf Dom(ω) < t_now − δ ∧ t_now − δ ≤ sup Dom(ω) ≤ t_now.

so that Ω_D = Ω_D^rt(t_now) ∪ Ω_D^hist(t_now) ∪ Ω_D^mix(t_now). A mixed segment can be split at t_now − δ into ω = ω_hist ⊕ ω_rt with historicalPart and realTimePart.
