Detailed Description

Class representing a Diagnosis Service (s ∈ S_diag) of the Digital Twin.

A Diagnosis Service identifies faults, anomalies or inefficiencies of the ToI from the data it consumes: here, the values that fall outside a normal range.

Parameters
<T>the type of a datum d ∈ D.
