Detailed Description

Class representing the model inference or data assimilation function μ : Ω_D × M → M of DT = ⟨D, M, S, μ⟩.

Given a segment ω ∈ Ω_D and a model m ∈ M, μ(ω, m) = m' is the model m updated with ω. The model is updated in place, so m' is the same object as m and keeps the type of m (e.g., m ∈ M_pred ⇒ m' ∈ M_pred).

Key features of the class include:

  • Data observer pattern: it observes the data sources (ObserverDataManager) through one ObserverData per source; each new datum of the ToI is turned into a segment ω.
  • Synchronous assimilation of real-time segments (Ω_D^rt): applied at once.
  • Asynchronous assimilation of historical segments (Ω_D^hist): queued until flush().
  • Mixed segments (Ω_D^mix) are handled according to the MixedPolicy: split into ω_hist ⊕ ω_rt and assimilated part by part (default), or assimilated as a whole like a real-time or like a historical segment.
