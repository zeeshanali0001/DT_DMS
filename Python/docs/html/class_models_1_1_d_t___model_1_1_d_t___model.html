Detailed Description

Abstract base class representing a generic DT model m ∈ M of DT = ⟨D, M, S, μ⟩.

M is the set of DT models that represent the ToI virtually: M = M_desc ∪ M_pred ∪ M_presc, the descriptive (DT_Model_Descriptive), predictive (DT_Model_Predictive) and prescriptive (DT_Model_Prescriptive) models.

Every model belongs to the class of automata 𝒜 (M ⊆ 𝒜); hence this class extends DT_Automaton and inherits the 7-tuple ℳ = ⟨Λ, X, Y, Σ, Φ, Δ, Δ*⟩. A model is updated by the data assimilation function μ through assimilate().

A model is also the subject of the model observer pattern: the services coupled to it (add_service_to_be_updated()) are notified after each assimilation (notify_services()).

◆ assimilate()

None Models.DT_Model.DT_Model.assimilate ( self,
DT_DataSegment omega )

Assimilates a data segment into this model: the model side of μ(ω, m) = m'.

The model is updated in place, so m' keeps the type of m. By default each datum of ω is passed to update() in time order, then the coupled services are notified (notify_services()); subclasses can override it (e.g., to re-train a predictive model on a whole historical segment) and should then call notify_services() too.

Parameters
omegathe data segment ω.

◆ evaluate()

float Models.DT_Model.DT_Model.evaluate ( self,
float t )

Returns the value of the model at time t, m(t), to be compared with the datum ω(t) measured at the same time (DT_DMS.check_models_versus_data).

By default a model gives no value in time and this method returns NaN; a model that describes or predicts the measured signal (e.g., an interpolation) overrides it.
