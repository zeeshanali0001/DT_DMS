Detailed Description

Live chart of the sine example: it plots the raw sine data measured on the ToI (real space) and the value of the DT model (virtual space).

It uses matplotlib in interactive mode, as the Java version uses XChart. matplotlib is optional: available() tells whether a chart window can be shown (matplotlib installed and a display available).
