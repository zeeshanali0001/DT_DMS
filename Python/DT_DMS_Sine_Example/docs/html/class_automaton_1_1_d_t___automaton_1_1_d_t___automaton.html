Detailed Description

Abstract base class representing the class of automata 𝒜 of the DT-DMS framework.

DT models and DT services belong to the same class of automata, i.e., M ⊆ 𝒜 and S ⊆ 𝒜. Therefore both DT_Model and DT_Service inherit from this class. Each automaton, whether discrete, continuous or hybrid, is specified with HiLLS (based on DEVS) as the 7-tuple (written ℳ for a model and 𝒮 for a service): 

ℳ = ⟨ Λ, X, Y, Σ, Φ, Δ, Δ* ⟩        𝒮 = ⟨ Λ, X, Y, Σ, Φ, Δ, Δ* ⟩

Mapping of the 7-tuple to this class:

  • Λ: parameters, the parameter set (context assumptions).
  • X: inputs, the input set (what is received from the ToI).
  • Y: outputs, the output set (what is provided to, or influences, the ToI).
  • Σ: state, the state variables; its current content is the state q ∈ Q.
  • Φ: phases, the phase set, each phase being a Phase.
  • Δ: transitions, the phase-to-phase transition set, each being a Transition.
  • Δ*: initialization, the initialization Initialization.

A state q ∈ Q is represented as a dict that assigns a value to every state variable. NIL components of the formalism are represented by None.
