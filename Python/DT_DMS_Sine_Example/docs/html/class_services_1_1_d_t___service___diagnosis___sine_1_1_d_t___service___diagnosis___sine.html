Detailed Description

Diagnosis service of the sine example (s ∈ S_diag): it detects the anomalies of the measured sine wave.

The service is coupled to the Cubic B-Spline model and consumes the latest measured value: s(m, ω) compares the value d of ω with the value expected by the model at the same time; the difference is the residual. An anomaly is reported when the residual exceeds the threshold.

It can also check the interpolation itself at random points between the samples (perform_random_check()), against the exact sine function.

The service is specified as the automaton 𝒮 = ⟨Λ, X, Y, Σ, Φ, Δ, Δ*⟩:

  • Λ = {threshold}: the largest residual considered normal.
  • X = {data}: a measured sine value.
  • Y = {anomaly}: the residual of an anomalous value.
  • Σ = {residual}: the residual of the last value checked.
  • Φ = {IDLE ⟨residual ≥ 0, NIL, ∞⟩, CHECK ⟨residual ≥ 0, NIL, 0⟩}.
  • Δ^in: IDLE → CHECK on (data, d), Update: residual := |d − m(t)|.
  • Δ^time: CHECK → IDLE, Guard: residual > threshold, Send: (anomaly, residual).
  • Δ^time: CHECK → IDLE, Guard: residual ≤ threshold, no output.
  • Δ* = ⟨IDLE, NIL, 0⟩.

float Services.DT_Service_Diagnosis_Sine.DT_Service_Diagnosis_Sine.perform_random_check ( self,
int number_of_points_to_check,
int seed,
bool verbose )

Checks the interpolation of the sine function at random points: draws number_of_points_to_check abscissas x uniformly in the domain of the model and compares sin(x) with the value of the B-spline at x.

Unlike execute_service(), which checks the measured values, this check uses the exact sine function and points between the samples.

Parameters
number_of_points_to_checkthe number of random points.
seedthe seed of the random generator (the same seed gives the same points).
verboseTrue to print one line per point.
Returns
the largest deviation |sin(x) − m(x)| found (NaN if no Cubic B-Spline model with data is coupled to the service).
