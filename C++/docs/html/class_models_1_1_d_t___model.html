Detailed Description

template<typename T>
class Models::DT_Model< T >

Abstract base class representing a generic DT model m ∈ M of DT = ⟨D, M, S, μ⟩.

M is the set of DT models that represent the ToI virtually: M = M_desc ∪ M_pred ∪ M_presc, the descriptive (DT_Model_Descriptive), predictive (DT_Model_Predictive) and prescriptive (DT_Model_Prescriptive) models.

Every model belongs to the class of automata 𝒜 (M ⊆ 𝒜); hence this class extends Automaton::DT_Automaton and inherits the 7-tuple ℳ = ⟨Λ, X, Y, Σ, Φ, Δ, Δ*⟩. A model is updated by the data assimilation function μ through assimilate(). This abstract class is the basis of implementation of the Strategy design pattern.

A model is also the subject of the model observer pattern: the services coupled to it (addServiceToBeUpdated()) are notified after each assimilation (notifyServices()).

◆ assimilate()

template<typename T>
virtual void Models::DT_Model< T >::assimilate ( const Data::DT_DataSegment< T > & omega)
inlinevirtual

Assimilates a data segment into this model: the model side of μ(ω, m) = m'.

The model is updated in place, so m' keeps the type of m. By default each datum of ω is passed to update() in time order, then the coupled services are notified (notifyServices()); subclasses can override it (e.g., to re-train a predictive model on a whole historical segment) and should then call notifyServices() too.

Parameters
omegathe data segment ω.

template<typename T>
virtual double Models::DT_Model< T >::evaluate ( double t) const
inlinevirtual

Returns the value of the model at time t, m(t), to be compared with the datum ω(t) measured at the same time (DT_DMS::checkModelsVersusData).

By default a model gives no value in time and this method returns NaN; a model that describes or predicts the measured signal (e.g., an interpolation) overrides it.
