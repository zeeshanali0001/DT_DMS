Detailed Description

The class of automata (𝒜) of the DT-DMS framework.

DT models and DT services are specified with the same formalism because both belong to the same class of automata: M ⊆ 𝒜 and S ⊆ 𝒜. An automaton, whether discrete, continuous or hybrid, is specified with HiLLS (based on DEVS) as the 7-tuple ⟨Λ, X, Y, Σ, Φ, Δ, Δ*⟩.
