Detailed Description

template<typename T>
class Services::DT_Service_Monitoring< T >

Class representing a Monitoring Service (s ∈ S_moni) of the Digital Twin.

A Monitoring Service observes the state of the ToI in real time: it compares the latest value of a monitored entity against thresholds and raises an alert when it is out of bounds.

Tthe type of a datum d ∈ D.
