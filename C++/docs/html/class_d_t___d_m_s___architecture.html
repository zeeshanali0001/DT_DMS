Detailed Description

template<typename T>
class DT_DMS_Architecture< T >

The DT_DMS_Architecture class connects all classes of the DT-DMS framework.

It is a Digital Twin (DT_DMS) with one named component of each kind: one data source, the three types of models, the five types of services and the data assimilation function. Its collaboration diagram (generated by Doxygen/Graphviz) is the architecture image of the framework.

Assign the fields, then call connect() so that every component belongs to D, M or S and is reached by μ. The example run is in DT_DMS_Architecture.cpp (main).
