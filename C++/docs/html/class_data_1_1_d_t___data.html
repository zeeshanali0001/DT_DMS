Detailed Description

template<typename T>
class Data::DT_Data< T >

Class representing a source of data collected from the ToI, i.e., a part of D in DT = ⟨D, M, S, μ⟩.

The collected data is either historical or real-time, D = D_hist ∪ D_rt. The classification depends only on the measurement time: a datum d = ω(t) is real-time iff t ≥ t_now − δ, and historical otherwise, where t is the measurement time, t_now the current time and δ the data scope during which data is considered real-time.

Key features of the class include:

  • Every datum is recorded with its measurement time in a segment ω (DT_DataSegment).
  • getRealTimeData() and getHistoricalData() give D_rt and D_hist of the source.
  • Its characterization (DT_DataCharacterization) tells how the data must be interpreted (unit, signal type, sensor precision, calibration, ...).
  • It is the subject of the observer pattern (Mu::ObserverDataManager): each new datum is pushed to the registered observers, in particular to the data assimilation function μ.
