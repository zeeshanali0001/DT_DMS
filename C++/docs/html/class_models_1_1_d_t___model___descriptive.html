Detailed Description

template<typename T>
class Models::DT_Model_Descriptive< T >

Represents a descriptive model (m ∈ M_desc) of the Digital Twin.

A descriptive model describes what happened or what is happening in the ToI: it summarizes and interprets the historical and real-time data it has assimilated.

Template Parameters
Tthe type of a datum d ∈ D.
