Detailed Description

template<typename T>
class Services::DT_Service< T >

Abstract base class representing a generic DT service s ∈ S of DT = ⟨D, M, S, μ⟩.

S is the set of DT services: S = S_moni ∪ S_pred ∪ S_diag ∪ S_opti ∪ S_cont, the monitoring (DT_Service_Monitoring), prediction (DT_Service_Prediction), diagnosis (DT_Service_Diagnosis), optimization (DT_Service_Optimization) and control (DT_Service_Control) services.

A service is parameterized by a model m ∈ M and/or the data segment(s) it consumes ω ∈ Ω_D: s : M × Ω_D → Y_s, where Y_s is the output produced by s (execute()). Services are specified with the same formalism as models because both belong to the class of automata 𝒜 (S ⊆ 𝒜); hence this class extends Automaton::DT_Automaton and inherits the 7-tuple 𝒮 = ⟨Λ, X, Y, Σ, Φ, Δ, Δ*⟩. This abstract class is the basis of implementation of the Strategy design pattern.

A service observes the data (Mu::ObserverData) and the model it is coupled to (Mu::ObserverModel): updateWithModel() is called each time μ has updated that model.
