Detailed Description

Chart of the sine example: it plots the raw sine data measured on the ToI (real space) and the value of the DT model (virtual space).

The Java version shows a live window with the XChart library. The C++ version needs no graphics library: it collects the same points with updateChart() and writes them as an SVG image (open it in any web browser) and as a CSV file (for a spreadsheet, gnuplot, Python, ...).
