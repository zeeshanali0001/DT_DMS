Detailed Description

Cubic B-Spline model of the sine example: a descriptive model (m ∈ M_desc) that represents the measured sine wave by a smooth curve.

The assimilated values are the control points of a uniform cubic B-spline: the i-th value assimilated is the control point of time leftEndpoint + i × step. The data must therefore be assimilated in time order, one value per step. (The first C++ version used boost::math::interpolators::cardinal_cubic_b_spline; this version needs no external library and gives the same model as the Java version.)

The model is specified as the automaton ℳ = ⟨Λ, X, Y, Σ, Φ, Δ, Δ*⟩:

  • Λ = {step, leftEndpoint}: the sampling assumptions.
  • X = {data}: a measured sine value.
  • Y = {updated}: the number of control points after an update.
  • Σ = {count, last}: the number of control points and the last value assimilated.
  • Φ = {WAIT ⟨count ≥ 0, NIL, ∞⟩, UPDATE ⟨count ≥ 1, NIL, 0⟩}.
  • Δ^in: WAIT → UPDATE on (data, d), Update: count := count + 1; last := d.
  • Δ^time: UPDATE → WAIT, Send: (updated, count).
  • Δ* = ⟨WAIT, NIL, 0⟩.
